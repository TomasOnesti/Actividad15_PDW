# Actividad-15-PWD



Descripción



Este proyecto consiste en el desarrollo de una aplicación web complementaria al videojuego 2D Malvinas: Voces del Frente, ambientado en la Guerra de Malvinas.



La página permite registrar enfrentamientos y consultar estadísticas relacionadas con el desempeño del jugador, manteniendo un historial de las partidas registradas.



Tecnologías utilizadas



HTML5: estructura de la aplicación.



CSS3: diseño visual y adaptación responsive.



JavaScript: lógica, cálculos y manipulación dinámica del contenido.



LocalStorage: almacenamiento de los registros en el navegador.



Funcionalidades



Registrar nuevos enfrentamientos.



Indicar la misión realizada.



Registrar la cantidad de enemigos eliminados.



Registrar el tiempo empleado en cada enfrentamiento.



Calcular automáticamente el puntaje obtenido.



Consultar la cantidad total de enfrentamientos.



Visualizar el total de enemigos eliminados.



Consultar el puntaje acumulado.



Mostrar el mejor tiempo registrado.



Eliminar enfrentamientos individuales.



Vaciar completamente el historial.



Guardar los registros mediante LocalStorage para conservarlos al recargar la página.

Instalación y ejecución



Descargar o clonar el repositorio.



Abrir la carpeta del proyecto.



Ejecutar el archivo index.html en un navegador web.



Completar el formulario para registrar un enfrentamiento.



Consultar las estadísticas y el historial generado.



No es necesario instalar dependencias externas para utilizar la aplicación.



Almacenamiento



Los datos se almacenan en el navegador mediante localStorage, utilizando la clave:



malvinas\_historial



Esto permite conservar los enfrentamientos registrados incluso después de cerrar o actualizar la página.
